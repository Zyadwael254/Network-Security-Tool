# Network-Security-Tool
Network Security Tool
إزاي تقدر تقيم أمان شبكة كاملة في وقت قصير بدل ما تراجع كل حاجة يدويًا؟
وهل ينفع نحدد مشاكل الشبكة قبل ما تتنفذ فعليًا؟

مع الشغل على Network Security لاحظت إن عملية مراجعة أي Network Design (خصوصًا لو في صورة JSON أو Topology) بتاخد وقت كبير وبتعتمد بشكل أساسي على المراجعة اليدوية.

علشان كده اشتغلت على Tool تساعد في الموضوع ده 👇

🚀 NetSec Analyzer

---

💡 الفكرة ببساطة:
الأداة بتاخد ملف JSON فيه تفاصيل الشبكة، وتعمل عليه تحليل شامل يوضح مستوى الأمان والمشاكل الموجودة.

---

📥 المدخلات (Input):
ملف JSON بيحتوي على:

* الأجهزة (Routers / Switches / Firewalls / Servers)
* IP Addresses
* البروتوكولات المستخدمة
* البورتات المفتوحة
* VLANs و Segments
* ACLs و Firewall configs
* إعدادات زي Gateway / DNS / NTP / Encryption

---

📊 المخرجات (Output):
بعد تشغيل الأداة، بتطلعلك:

• Security Score من 100 يوضح مستوى أمان الشبكة
• تصنيف واضح (Secure / Vulnerable / …)
• قائمة بالمشاكل (Findings) متقسمة حسب الخطورة:
Critical / High / Medium / Low
• شرح لكل مشكلة فين وليه حصلت
• Suggestions أو Remediation لكل مشكلة علشان تتصلح

---

🧠 الأداة بتساعدك تكتشف:

* مشاكل في الـ IPs أو Duplicate / Invalid
* استخدام بروتوكولات غير آمنة زي Telnet و HTTP
* غياب Firewall أو سوء مكانه
* ضعف في Network Segmentation و VLANs
* ACLs ناقصة أو مش متطبقة صح
* بورتات مفتوحة خطر
* Weak Credentials
* غياب Monitoring (Syslog / SNMP)
* مشاكل في Encryption أو DNS / NTP

---

🎯 الهدف من التول:
تقليل الوقت اللي بيضيع في المراجعة اليدوية
تقديم تقييم واضح وسريع لأي Network Design
مساعدة مهندس الشبكات إنه ياخد قرارات مبنية على Data
واكتشاف مشاكل ممكن تعدي بسهولة لو المراجعة كانت Manual

---

في النهاية الهدف من المشروع كان إني أوصل لنقطة إنك تقدر:
• تحلل شبكة كاملة في ثواني
• تعرف المشاكل قبل ما تأثر فعليًا
• وتبقى عندك رؤية واضحة عن مستوى الأمان.
